Civic reporting, with a memory

Report once. Understand together. Act as a community.

Residents often report the same pothole, the same garbage pile, the same dead streetlight, and never learn whether anyone else did. FixMyCity connects those reports so a neighbourhood can see what keeps coming back.

The problem

Five complaints about one pothole look like five separate problems.

  • Duplicate reports.People file the same issue again and again because there is no shared view of what is already reported.
  • No way to follow up.A report goes in and the resident rarely finds out what happened next.
  • Patterns stay hidden.Streets with the same problem every month are hard to spot when each report sits on its own.

How it works

From one photo to a neighbourhood pattern.

Report it

Add a photo, pick a category and drop a pin on the map. Your report gets its own ID.

Neighbours confirm

Others nearby tap whether the issue still exists, has got worse, or looks fixed.

The radar connects reports

Reports of the same type within a set distance are grouped into a suggested cluster.

Track progress

Every status change is recorded, so anyone can see where a report stands.

Features

More than a complaint form.

Repeat Issue Radar Headline feature

Simple, explainable matching by category and distance. You can see why reports were grouped, and the radius is adjustable.

Smart issue reporting

Title, category, description, photo and map location in one short form. Each report is trackable from the moment it is filed.

Community verification

One vote per resident per report. Community confirmation is kept separate from any official check.

Neighbourhood Pulse

Open and resolved counts, common categories, repeat hotspots and weekly trends for your area.

Transparent status

A clear timeline from submitted to resolved, with a history of every change.

Action Circles

Voluntary clean-ups, tree planting and awareness drives that residents can start and join. Never hazardous repairs.

Report status

Every report has a visible path.

Submitted→ Community confirmed→ Acknowledged→ In progress→ Resolved

A note on trust. “Community confirmed” means neighbours agree the issue exists. It is not an official verification. The administrator view in this prototype is a demonstration role and does not imply a partnership with any city authority.

Neighbourhood Pulse

See what your street keeps running into.

A local dashboard shows which problems are most common, how many are still open, and where the same issue returns. It is built from the reports residents submit.

Built with care

Privacy and honesty by default.

People stay out of the frame

Photos should show the problem, not faces or vehicle number plates. Reporters are reminded of this before every upload, because photos are shown publicly.

Demo data is labelled

Anything that is an example, including the numbers on this page, says so. Nothing here is official city data.

Independent of government

FixMyCity is a community project. It does not use official logos or claim any government affiliation.
